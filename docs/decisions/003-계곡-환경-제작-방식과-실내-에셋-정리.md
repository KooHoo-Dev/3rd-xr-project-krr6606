# 003. 계곡 환경 제작 방식과 실내 에셋 정리

- 날짜: 2026-11-16
- 결정한 사람: 사용자 (Claude는 선택지 · 장단점 · 추천 제시)
- 태그: `#AI리더십` `#구조화`
- 관련: [002](002-물풍선-기획-전환.md) (기획 전환)

## 문제
기획이 물풍선 · 야외 여름 계곡으로 바뀌었다. 이 컴퓨터에서 바뀐 기획에 맞춰 에셋을 바꾸고 데모 씬에 적용해야 한다.
1차 빌드(2026-11-23)까지 7일이 남았는데 게임 로직은 아직 없다. 그래서 에셋 작업은 짧게 끝내야 한다.

## 결정 1. 계곡 환경 제작 방식
| 선택지 | 장점 | 단점 |
| --- | --- | --- |
| **A. Blender 스크립트 (채택, Claude 추천과 같음)** | 다트 · 소품과 로우폴리 스타일이 맞음. 팔레트 머티리얼 1개라 Quest 성능이 안정적임. 빠름 | AI가 만든 비중이 커짐 (generated) |
| B. Unity에서 직접 (Terrain · ProBuilder) | 사용자가 직접 만든 몫이 커지고 배우는 것도 많음 | 시간이 더 듦. Terrain은 Quest에서 무거울 수 있음 |
| C. 무료 에셋 팩 | 가장 빠름 | 스타일이 안 맞을 수 있음. 용량, 라이선스 확인이 필요함 |

이유: 제자리 플레이라 보이는 범위가 앞쪽 반원 정도로 좁다. 남은 시간은 게임 로직에 써야 한다.

## 결정 2. 안 쓰는 실내 에셋은 삭제
씬에서 빼기만 해도 빌드에는 들어가지 않는다. 하지만 폴더를 깔끔하게 하려고 파일까지 지운다. git 기록에서 되살릴 수 있다.
- 삭제: 다트판(모델 · 텍스처 · 머티리얼 · 생성 스크립트), 실내 방, 백보드, 바 테이블(통나무 받침대로 대체), 네온 간판 2종, 펜던트 조명, 바 의자, 포스터, 칠판 점수판, 실내 미리보기 이미지
- 유지: 다트, 다트통, 던지는 선, UI 스프라이트, 팔레트 텍스처 · `M_Palette`

## 결정 3. 새 에셋 사양 (사용자 선택, 세 가지 모두 Claude 추천과 같음)
| 항목 | 선택지 | 결정 |
| --- | --- | --- |
| 물풍선 모델 | FBX 4개 (색 · 크기별) / FBX 1개 + 머티리얼 4개 | **FBX 4개**: 팔레트 머티리얼 1개를 유지하고, 크기가 모델에 고정되어 실수가 적음 |
| 다트통 받침 (윗면 1.0 m) | 통나무 받침대 / 큰 평평한 바위 / 나무 캠핑 테이블 | **통나무 받침대** |
| 계곡 구성 | Claude 초안 | **초안 그대로**: 자갈 강변(플레이어) → 앞 2.5~6 m 얕은 시냇물 → 양옆 바위 언덕 → 나무 6~10그루 → 먼 산 실루엣. 하늘은 Unity Skybox, 약 40k tris 이내 |

## 영향
- 계곡 환경은 사용자가 만드는 것에서 **AI가 생성하고 사용자가 검토하는 것**으로 역할이 바뀐다 ([asset-plan](../planning/asset-plan.md) 역할 분담 갱신).
- 팔레트에서 실내용 색 칸(16번 이후)은 지우지 않고 남겨 둔다. 계곡 색은 그 뒤에 추가한다. 남은 칸은 256px 텍스처 안의 빈 공간일 뿐이라 비용이 거의 없다. 칸을 지우거나 순서를 바꾸면 그 칸을 쓰는 모델의 색이 바뀔 위험이 있다.
