## 문제
씬에 필요한 에셋(다트, 다트판, 다트통, UI, 환경)을 7일 일정 안에, Quest 성능을 지키면서, 퀄리티 있게 마련해야 한다.
또 기획서의 다트판(동심원 4구역)을 그대로 만들지, 일반 다트판으로 바꿀지 정해야 했다.

## 선택지
| 구분 | 선택지 | 장점 | 단점 |
| --- | --- | --- | --- |
| 스타일 | A. 깔끔한 로우폴리 | Quest 성능 유리, 통일감, 스크립트 제작에 적합 | 사실감 낮음 |
| | B. 사실적 PBR | 겉보기 퀄리티 | 외부 텍스처 필요, 무거움, 시간 |
| 제작 | 1. Blender 파이썬 스크립트 → FBX·PNG | 정확한 치수·피벗, 재생성 가능 | 모델링은 AI 몫 |
| | 2. ProBuilder 직접 모델링 | 학습 | 둥근 물체 퀄리티 낮음, 시간 |
| | 3. 무료 에셋팩 | 빠름 | 스타일 혼재, 라이선스 확인 |

## 결정
- **스타일 A + 제작 방식 1** (Claude 추천안 채택)
- **다트판은 일반 다트판과 똑같이**, 단 **중앙(Inner Bull) 점수만 777점**
  - 기획서의 "동심원 4구역(777/40/20/10)" 규칙을 대체한다.

## 이유
- 이 프로젝트에서 배울 핵심은 XRI·물리이므로, 아트는 AI가 생성하고 사람은 검토·조립·상호작용 설정에 집중한다.
- 생성 스크립트를 `Tools/AssetGen/`에 남겨 두면, 수정 요청 시 다시 생성할 수 있고 AI 기여 범위가 분명하다.

## 다트판 점수 규칙 (코드와 텍스처가 함께 쓰는 값)
| 구역 | 반지름 (중심에서, mm) | 점수 |
| --- | --- | --- |
| Inner Bull | 0 ~ 6.35 | **777** |
| Outer Bull | 6.35 ~ 15.9 | 25 |
| Single (안쪽) | 15.9 ~ 99 | 섹터 숫자 × 1 |
| Triple 링 | 99 ~ 107 | 섹터 숫자 × 3 |
| Single (바깥) | 107 ~ 162 | 섹터 숫자 × 1 |
| Double 링 | 162 ~ 170 | 섹터 숫자 × 2 |
| 바깥 | 170 ~ | 0 (빗나감) |

- 섹터: 맨 위부터 시계 방향으로 `20 1 18 4 13 6 10 15 2 17 3 19 7 16 8 11 14 9 12 5`, 한 섹터 18°, 20은 위쪽 정중앙(±9°).
- 다트판 모델 좌표: **앞면 = 로컬 -Z**, 로컬 +X = 플레이어 기준 오른쪽, 로컬 +Y = 위, 피벗 = 판 앞면 중심.
