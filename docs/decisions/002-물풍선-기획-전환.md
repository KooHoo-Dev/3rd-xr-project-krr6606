# 002. 다트판 → 물풍선 기획 전환

- 날짜: 2026-11-16
- 결정한 사람: 사용자 (Claude는 수정안 초안 · 선택지 · 추천 제시, 사용자가 초안을 직접 고쳐 확정)
- 태그: `#AI리더십` `#구조화`
- 대체하는 것: [001](001-아트-스타일과-다트판-규칙.md)의 다트판 점수 규칙

## 문제
다트를 던져 다트판을 맞히는 구성을, 다트로 공중의 물풍선을 터트리는 구성으로 바꾸고 싶다.
사용자가 원하는 경험: 일렬로 선 풍선을 한 번에, 혹은 빠르게 여러 번 터트릴 때
**마리오의 코인처럼 시원하고 중독적이며 기분 좋은** 피드백(터지는 소리, 쏟아지는 물).

## 결정
| 항목 | 결정 |
| --- | --- |
| 목표물 | 물결(웨이브)마다 떠올라 정해진 시간 체공하는 물풍선. 다트판은 없앰 |
| 풍선 종류 | 빨강 35 cm·10점 / 파랑 28 cm·20점 / 초록 22 cm·30점 / **금빛 12 cm·777점** (첫 테스트 값) |
| 금빛 풍선 | 항상 1개, 계속 움직임, 언제든 도전 가능, 콤보 배율 없이 777점 고정 |
| 콤보 | 하나의 콤보 카운터 (1.5초 안에 다음 터짐 → 콤보 +1, 배율 최대 ×3) |
| 끝나는 조건 | **60초 시간 제한**, 다트는 다트통에 자동으로 채워짐 |
| 승패 | 목표 점수(예: 300점) 이상이면 승리 |
| 환경 | 야외 여름 계곡 (사용자가 다른 컴퓨터에서 제작해 적용) |

상세 규칙: [planning/concept.md](../planning/concept.md)

## 끝나는 조건 선택지
| 선택지 | 장점 | 단점 |
| --- | --- | --- |
| A. 다트 7개 제한 | 기존 다트통·규칙 그대로 | 한 판에 7번뿐이라 ‘빠르게 여러 번’의 맛이 약함 |
| **B. 60초 시간 제한 (채택, Claude 추천과 같음)** | 연달아 던지는 리듬과 ‘한 판 더’가 살아남 | 다트 채우기 기능이 더 필요함 |
| C. 5물결 제한 | 판 길이가 일정함 | 물결 사이에 기다리는 시간이 생김 |

## 사람이 고친 부분  #AI리더십
Claude 초안(Claude 문서)을 사용자가 직접 수정해 확정했다. 초안과 달라진 점:
- 핵심 경험 문장을 ‘다트 하나가 일렬로 선 풍선을 꿰뚫고 지나가며 터트리는 쾌감’으로 좁힘
- 일반 풍선 3색의 움직임을 모두 ‘떠오른 뒤 거의 멈춤’으로 통일 (초안: 색마다 흔들림이 다름)
- 체공 시간 예시 4초 → 6초
- 올 클리어 피드백 소리를 ‘짧은 팡파르’로, 금빛 풍선 소리를 ‘차별화된 팡 + 동전 쏟아지는 소리’로 수정
- 초안의 ‘재사용 에셋’, ‘요구사항·일정’ 장을 기획서에서 뺌 (에셋 목록은 [asset-plan](../planning/asset-plan.md)에서 관리)

## 영향
- 다트판, 다트판 백보드, “BULL 777” 네온은 쓰지 않는다
- 실내 다트 바 방(DartRoom 등)은 계곡 환경이 들어오기 전까지 테스트용으로만 남는다
- 새로 필요: 물풍선 모델 4종, 물 효과(튐·쏟아짐), 사운드, 풍선 생성·체공·콤보·타이머 로직, 다트 자동 채우기
