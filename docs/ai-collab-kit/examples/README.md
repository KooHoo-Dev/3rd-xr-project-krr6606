# 독자별 예시 문서

> **읽는 이:** 사용자 (피드백할 때), Claude (같은 종류 문서를 쓰기 전 참고).
> **버전:** v0.2 (2026-11-23) — 라운드 1 피드백 반영. 피드백 원문은 [../feedback/round-1-원문.md](../feedback/round-1-원문.md), 피드백을 단 v0.1 원본은 [../feedback/round-1-원본/](../feedback/round-1-원본/).

예시는 모두 **작성 메모(본문 아님) → 본문** 순서입니다. 작성 메모에는 독자 카드, 이번에 바꾼 것, 본문에서 빼서 사용자에게 확인받을 것이 들어 있습니다. 본문은 그대로 가져다 쓸 수 있는 글입니다.
사실은 모두 이 프로젝트 기록(결정 기록, devlog, 커밋, 코드)에서 가져왔고, 기록에 없는 것은 본문에 넣지 않고 작성 메모에 남겼습니다.

## v0.2에서 지킨 것 (라운드 1)
- 사람이 읽는 문서(E1, E2, E3, E5, E6)는 사용자가 직접 쓴 글처럼 썼습니다. 1인칭과 ~습니다 체로 쓰고, 문장을 서로 이어지게 했습니다.
- 본문에는 `질문:`, `맥락:`, `[확인 필요]` 같은 라벨, AI 입장에서 하는 말, 화살표 요약을 두지 않았습니다.
- AI가 읽는 문서(E4, E7)는 라벨 형식을 유지했습니다. 이 구분이 맞는지는 확인이 필요합니다.
