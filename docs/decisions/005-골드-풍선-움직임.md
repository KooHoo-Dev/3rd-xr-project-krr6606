# 005. 골드 풍선 움직임

- 날짜: 2026-11-17
- 결정한 사람: 사용자 (Claude는 선택지 · 장단점 · 추천 제시)
- 태그: `#AI리더십` `#구조화`
- 관련: [004](004-풍선-만료-알림-방식.md)

## 문제
골드 풍선(777점)은 일반 풍선과 다르게, 범위 안에서 X · Y가 맞추기 어렵게 움직여야 한다.

## 결정 1. 움직임 방식
| 선택지 | 장점 | 단점 |
| --- | --- | --- |
| **A. 랜덤 지점 점프 (채택, Claude 추천과 같음)** | 기존 DOTween을 그대로 씀. 방향 · 속도가 매번 바뀌어 예측이 어려움 | 범위 · 시간 수치 조정이 필요 |
| B. 펄린 노이즈 | 끊김 없이 부드러움 | 예측이 쉬운 편. DOTween과 따로 놂 |
| C. 고정 패턴 (8자 · 지그재그) | 구현이 가장 쉬움 | 몇 번 보면 패턴이 읽힘 |

## 결정 2. 코드 위치
**별도 컴포넌트 `GoldBalloonMover` (채택, Claude 추천과 같음).** `WaterBalloon`은 골드일 때 체공 시퀀스를 건너뛴다. 대안은 `WaterBalloon` 안의 분기였다. 그 경우 인스펙터 변수가 섞인다.

## 결정 3. 수명
골드 풍선은 **맞을 때까지 유지**한다. 만료 하강은 없다. (사용자 선택)
