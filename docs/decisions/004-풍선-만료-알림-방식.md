# 004. 풍선 만료(점수 없이 사라짐) 알림 방식

- 날짜: 2026-11-17
- 결정한 사람: 사용자 (Claude는 선택지 · 장단점 · 추천 제시)
- 태그: `#AI리더십` `#구조화`

## 문제
풍선이 떠올라 체공 시간이 끝나면 내려가서 점수 없이 삭제된다. 그런데 `BalloonSpawner`는 `OnBalloonPops`에서만 스폰 포인트를 비운다. 만료된 풍선의 자리는 계속 "사용 중"으로 남는다.

## 선택지
| 선택지 | 장점 | 단점 |
| --- | --- | --- |
| **A. `OnBalloonExpired` 이벤트를 따로 추가 (채택, Claude 추천과 같음)** | 터짐과 만료의 의미가 분리됨. 만료 때만 다른 처리를 붙이기 쉬움 | Spawner에 구독 줄이 하나 늘어남 |
| B. `OnBalloonRemoved` 하나로 통합 | 코드가 가장 짧음 | 받는 쪽에서 사라진 이유를 구분할 수 없음 |

## 결정과 이유
A를 골랐다. 사용자의 이유: 만료 시 피드백 계획은 아직 없다. 하지만 만료 때 처리를 다르게 할 수 있으니 분리해 둔다.
