# 006. 손 추적(XR Hands) 도입

- 날짜: 2026-11-20
- 결정한 사람: 사용자 (Claude는 현황 조사 · 선택지 · 추천 제시)
- 태그: `#AI리더십` `#구조화`
- 관련: [002](002-물풍선-기획-전환.md)

## 문제
Quest에서 컨트롤러로 다트를 던져보니 손맛이 살지 않았다. 사용자가 꼽은 이유는 두 가지다.
1. 다트를 쥐는 손 모양·감각과 컨트롤러를 쥐는 손 모양·감각이 너무 다르다.
2. 컨트롤러가 다트보다 훨씬 무거워서 빠르게 휘두르는 느낌이 나지 않는다.

## 현황 (2026-11-20 조사)
- `com.unity.xr.hands` 1.8.1은 이미 설치되어 있다.
- OpenXR 손 추적 기능(Hand Tracking Subsystem, Meta Hand Tracking Aim, Hand Interaction Profile)은 Android · Standalone 탭 모두 꺼져 있다.
- 손 샘플(HandVisualizer, Hands Interaction Demo)은 아직 임포트하지 않았다.
- 테스트는 Quest Link / Air Link로 에디터 Play를 해서 한다. 에디터 Play는 Standalone 탭 설정을 쓴다.

## 선택지
| 선택지 | 장점 | 단점 |
| --- | --- | --- |
| **A. 손 + 컨트롤러 둘 다 (채택, Claude 추천과 같음)** | 손 던지기가 기대에 못 미쳐도 컨트롤러로 시연할 수 있음 | 설정할 양이 가장 많음 |
| B. 손만 | 구성이 단순 | 손 던지기가 실패하면 대안이 없음 |
| C. 컨트롤러 유지 + 던지기 수치 조정 | 마감 위험이 가장 적음 | 쥐는 감각 · 무게 차이는 해결하지 못함 |

## 결정
A. 본 씬(`DartDemo`)을 바로 바꾸지 않고, 복제한 테스트 씬에서 먼저 검증한다.

## 위험과 대응
- 마감이 D-3이다(2026-11-23). 손 추적 작업의 시간 상한은 하루로 잡고, 넘기면 컨트롤러로 시연하는 것을 기본으로 한다. (상한은 Claude가 제안함. 사용자 확인 필요)
- 손을 빠르게 휘두르면 추적이 끊기거나, 놓는 순간이 늦게 인식되어 던지는 속도가 약해질 수 있다. 기기에서 직접 확인한다.
- UI 레이 · 레이어 재설정 같은 자잘한 설정과 디자인 요소는 AI에 맡긴다. (사용자 방침)
