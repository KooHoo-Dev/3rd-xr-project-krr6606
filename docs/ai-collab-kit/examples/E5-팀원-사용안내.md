```
독자:      H5 이 프로젝트를 처음 받은 팀원
읽는 목적: 손 추적 테스트 씬을 만들어 손으로 다트를 던져 본다
읽는 상황: 에디터 옆에 띄우고 한 단계씩 따라 함
```

## 본문

### 손 추적 테스트 씬에서 다트 던져 보기

Quest 헤드셋을 Quest Link(케이블)나 Air Link로 PC에 연결하고, 이 프로젝트를 Unity 에디터로 열어 둔 상태에서 시작합니다.

**1. 손 추적 기능이 켜져 있는지 확인합니다.**
Edit → Project Settings → XR Plug-in Management → OpenXR로 가서 **PC 탭**(모니터 모양 아이콘)을 엽니다. Hand Tracking Subsystem, Meta Hand Tracking Aim, Hand Interaction Profile 세 항목에 체크가 되어 있으면 됩니다.

![OpenXR 설정의 PC 탭에서 손 추적 기능 세 개에 체크된 모습](images/e5-1-openxr-pc.png)

**2. 테스트 씬을 만듭니다.**
상단 메뉴에서 Tools → Dart Challenge → **Build Hands Test Scene**을 누릅니다. `DartDemo_Hands` 씬이 새로 만들어지고 바로 열립니다. 원래 씬인 `DartDemo`는 바뀌지 않으니 걱정하지 않으셔도 됩니다.

![Tools 메뉴에서 Build Hands Test Scene을 고르는 모습](images/e5-2-menu.png)

**3. 헤드셋에서 Link를 켜고 에디터에서 Play를 누릅니다.**
헤드셋 안에서 내 손이 보이면 손 추적이 동작하는 것입니다.

![Play 중 손이 보이는 화면](images/e5-3-hands.png)

**4. 컨트롤러를 내려놓고 엄지와 검지로 다트를 집어 던져 봅니다.**
집었을 때 다트 끝이 하늘이 아니라 정면 쪽을 향하면 잘 된 것입니다.

![두 손가락으로 집은 다트의 끝이 정면을 향한 모습](images/e5-4-grab.png)

### 잘 안 될 때

| 이런 경우 | 이렇게 해 보세요 |
| --- | --- |
| 손이 보이지 않습니다 | 1번을 Android 탭이 아니라 PC 탭에서 했는지 확인해 주세요. Link로 하는 에디터 Play는 PC 탭 설정을 씁니다 |
| Tools 메뉴에 Dart Challenge가 없습니다 | Console 창에 빨간 컴파일 에러가 있는지 확인해 주세요. 에러가 있으면 메뉴가 만들어지지 않습니다 |
| 다트 끝이 하늘을 향합니다 | Hierarchy에서 손 아래의 `Dart Grip Offset`을 찾아 Rotation이 (45, -45, 0)인지 확인해 주세요 |

Quest에 APK로 빌드해서 테스트할 때는 1번과 같은 기능을 Android 탭에서도 켜 주셔야 합니다.
