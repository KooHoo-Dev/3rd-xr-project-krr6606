# E5. 팀원 · 다음 작업자용 — 사용 안내(how-to)

> 다른 주제: 손 추적 테스트 씬을 만들고 Quest Link로 확인하기.

## 독자 카드
```
독자:      H5 이 프로젝트를 처음 받은 팀원
읽는 목적: 손 추적 테스트 씬을 만들어 손으로 다트를 던져 본다
읽는 상황: 에디터 옆에 띄우고 한 단계씩 따라 함
아는 것:   Unity 에디터 기본. 이 프로젝트의 도구 메뉴 · 설정 위치는 모름
성공 기준: 질문 없이 끝까지 가서 손으로 다트를 잡을 수 있다
```

## 설계 메모
- **단계에는 행동만.** "왜"는 맨 아래 한 줄로 모았다. 따라 하는 중에는 읽지 않기 때문이다.
- **단계마다 확인 신호.** "이렇게 보이면 맞다"가 없으면 독자는 다음으로 넘어가도 되는지 모른다.
- **안 될 때**는 증상 → 할 일 표. 독자는 증상으로 찾는다.
- **E2와 다른 점:** 대안 · 선택 이유가 없다. 이 독자는 결정을 평가하지 않고 실행한다.

## 본문

### 손 추적 테스트 씬에서 다트 던져 보기

```피드백: 이러한 문서에는 간단한 설명 예시 스크린 샷이 있으면 더 좋아.```

**준비물:** Quest 헤드셋, Quest Link(케이블) 또는 Air Link 연결, 이 프로젝트를 연 Unity 에디터

1. **손 추적 기능이 켜져 있는지 확인한다.**
   Edit → Project Settings → XR Plug-in Management → OpenXR → **PC(Standalone) 탭**.
   - 확인: Hand Tracking Subsystem, Meta Hand Tracking Aim, Hand Interaction Profile이 체크되어 있다.
2. **테스트 씬을 만든다.** 메뉴 Tools → Dart Challenge → **Build Hands Test Scene**.
   - 확인: `Assets/_Project/Scenes/DartDemo_Hands.unity`가 생기고 열린다. 원본 `DartDemo.unity`는 바뀌지 않는다.
3. **헤드셋에서 Link를 켜고 에디터에서 Play를 누른다.**
   - 확인: 헤드셋 안에서 내 손이 보인다.
4. **컨트롤러를 내려놓고 두 손가락(엄지 · 검지)으로 다트를 집어 던진다.**
   - 확인: 다트 끝이 하늘이 아니라 정면 쪽을 향한다.

### 안 될 때
| 증상 | 할 일 |
| --- | --- |
| 손이 안 보인다 | 1번을 **PC 탭**에서 했는지 확인. 에디터 Play는 Android 탭이 아니라 PC 탭 설정을 쓴다 |
| 메뉴에 Tools → Dart Challenge가 없다 | Console에 컴파일 에러가 있는지 확인 |
| 다트 끝이 하늘을 향한다 | 손 리그의 `Dart Grip Offset` 회전이 (45, -45, 0)인지 확인 |

> 왜 PC 탭인가: Link로 하는 에디터 Play는 PC 앱으로 실행된다. Quest에 APK로 빌드할 때는 Android 탭에도 같은 기능을 켜야 한다.
