# 물풍선 터트리기

## 한 줄 소개
여름 계곡에서 새총으로 돌멩이를 쏘아 공중에 떠오른 물풍선을 꿰뚫고, 한 번에 혹은 연달아 터트리며 60초 안에 목표 점수를 넘기는 VR 게임.

## 사용한 XR 기능
- **XRI 잡기 (Grab):** 손 추적으로 새총 손잡이를 주먹 쥐어 잡기, 레이로 끌어와 잡기
- **XRI 잡고 당기기 (Grab + 스크립트):** 다른 손으로 주머니를 집어 당겼다 놓아 발사
- **XRI 선택 필터 (Select Filter):** 한 손이 새총을 쥐고 있으면 다른 손은 당기기만 가능
- **레이 UI:** 시작 / 다시하기 버튼
- **XR Hands 손 추적** + 컨트롤러 동시 지원 (OpenXR + Meta OpenXR, Meta Quest)

## 주요 기능
- **새총 조준과 발사:** 당긴 거리로 세기, 당긴 높이로 위아래 각도를 정하고, 놓기 전에 포물선 궤적을 보여 준다. 쏘면 돌멩이 10종 중 하나가 자동으로 장전된다.
- **관통:** 돌멩이가 풍선을 터트리고도 멈추지 않아, 일렬로 선 풍선을 한 번에 꿰뚫는다.
- **물풍선 4종:** 빨강 10점 · 파랑 20점 · 초록 30점, 계속 움직이는 작은 금빛 풍선은 777점.
- **콤보:** 1.5초 안에 연달아 터트리면 배율이 ×1.5, ×2 … 최대 ×3까지 오르고, '팡' 소리가 한 음씩 높아진다.
- **60초 · 목표 1000점:** 끝나면 성공/실패 결과 화면과 결과별 효과음, 다시하기.
- **피드백:** 터짐 효과와 물 튀는 연출, 금빛 풍선 팡파르, 새총 당기기 · 발사 · 받침대 복귀 효과음.
- **새총 받침대:** 놓은 새총은 6초 뒤 통나무 받침대로 돌아간다.

## 느낀점
VR 인터렉티브 툴킷은 정말 완성도 높고 필요한 기능이 다 있어서 VR기기만의 어려운 부분을 시간을 많이 써서 깊게 파고들지 않아도 손쉽게 작업 할 수 있었던 것 같습니다. 그리고 VR이라는 기기는 정말 플레이 경험과 느낌이 일반적인 pc나 콘솔, 모바일과는 차원이 달랐고, 직접 플레이 해가며 테스트를 했을 때, 처음에 주고자 했던 느낌이 전혀 나지 않아서 갈아엎고 직접 기기를 쓰고 테스트해가며 작업을 하게 됐습니다. 다른 생태계의 새로운 디바이스를 다루는 좋은 경험을 한 것 같습니다.
