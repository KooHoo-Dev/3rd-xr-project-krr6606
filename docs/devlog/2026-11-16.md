## 배운 것  #학습실행력
- 개념: XR Simple Interactable은 이벤트만 알리고, 물체를 손에 붙이는 것은 XR Grab Interactable / 컨트롤러의 Physics Layer Mask에 없는 레이어는 감지되지 않음(Interaction Layer와는 별개) / XRI는 잡을 때 isKinematic을 저장하고 놓을 때 되돌림 / kinematic 강체에는 속도를 넣을 수 없음
- 어디에 적용했나: `Dart.cs`의 `Throw()`(Select Exited에서 isKinematic 끄기), `Stop()`(속도 0 → isKinematic 켜기 순서), Near-Far Interactor의 Physics Layer Mask에 Dart 추가
